# Hasaki product card UI improvement

Bản demo cải tiến giao diện thẻ sản phẩm tham khảo từ Hasaki.vn, phục vụ bài tập Phát triển ứng dụng WEB/TMĐT.

## Cách chạy

1. Tải và giải nén thư mục.
2. Mở `index.html` bằng Chrome hoặc Edge.
3. Nhấn F12 → Toggle device toolbar (Ctrl+Shift+M) để xem giao diện điện thoại.

## Nội dung

- 4 sản phẩm minh họa: CeraVe, Bioderma, Cetaphil, Klairs.
- Giá được tham khảo từ ảnh chụp website do sinh viên cung cấp, không phải báo giá thời gian thực.
- Hình minh họa được tạo bằng SVG riêng, không sao chép ảnh sản phẩm trên website.
- Nút Thêm vào giỏ hàng chỉ minh họa giao diện. Không sử dụng JavaScript hoặc backend.

## Công nghệ

HTML5 và CSS3, bao gồm CSS Grid, Flexbox và Media Queries.
